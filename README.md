# RAIWAVE — Feel Every Frequency

> **Lead Engineer & Creator:** Kazi Raiyan  
> **Official Repository:** [https://github.com/kaziraiyan0123-hub/raiwave](https://github.com/kaziraiyan0123-hub/raiwave)  
> **Design Philosophy:** Premium, Immersive, Minimalist Neon Cyber-Acoustic  
> **Color Identity:** Midnight Black (`#090D13`), Wave Lime (`#B6F36B`), Ocean Teal (`#52D6C9`), Slate (`#202A34`)

RAIWAVE is an ultra-fast, zero-API universal music streaming, voice studio, and discovery platform engineered for both desktop and mobile web experiences.

---

## ⚡ Key Highlights & Capabilities

1. **Zero-API Universal Catalog & Instant Streaming:**
   - Real-time global top 50 charts and instant live search across millions of songs.
   - Clean, legal universal streaming engine without requiring paid API tokens or complex Google/Spotify developer setups.
   - 320kbps high-fidelity playback with smart fallback audio resolvers.

2. **Real-Time Live Discovery & Genre Frequencies:**
   - Live Apple iTunes & RSS dynamic chart integration.
   - Real-time dynamic genre switching (All, Hip-Hop, Pop, Electronic, Rock, R&B/Soul, Ambient/Chill, Jazz).
   - High-resolution 600×600 artwork caching with instant category filtering.

3. **Personal Account & Gmail-Maintained Library:**
   - Seamless profile sync with Gmail tracking (`kaziraiyan0123@gmail.com`).
   - Developer attribution badge honoring creator **Kazi Raiyan**.
   - Cloud backup and JSON export/import for personal playlists, liked tracks, and studio audio recordings.

4. **Integrated Studio Voice & Music Recorder:**
   - Direct Web Audio API microphone capture with real-time frequency visualizer.
   - Save voice notes, demos, vocals, and song sketches directly to "Studio Recordings" in your personal library.
   - Instant playback preview and local audio memo management.

5. **Signature Mobile & Desktop Responsive Design:**
   - Fluid responsive layout tailored to both desktop widescreen monitors and mobile phones.
   - Mobile bottom navigation dock (Home, Explore, Search, Library), top bar, and gesture-friendly full-screen player.
   - PWA (Progressive Web App) offline caching and home screen install capability.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/kaziraiyan0123-hub/raiwave.git
cd raiwave

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## 📦 Standalone Packages

- **Desktop (Windows):** Run `npm run build:exe` or execute the portable Windows runner `RAIWAVE.exe`.
- **Mobile (Android / PWA):** Open the live URL on any Android device and tap **"Install RAIWAVE"** / **"Add to Home Screen"** or install the generated standalone PWA APK package.
